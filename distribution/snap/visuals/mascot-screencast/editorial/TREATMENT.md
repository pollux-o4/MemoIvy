# MemoIvy · 작은 메모에서, 연결된 생각으로 — 트리트먼트 v2

스타일: Mascot Screencast(`living-screencast`). 가로 1920×1080, 30fps, 55초, 내레이션 없음, 한국어 자막 번인. 용도: Snap Store 소개 영상·스크린샷.

## 0. v1 적대 검토 → 결정

관점별로 v1(아이콘에서 태어난 마스코트 → 적기 → 모으기 → 연결하기 투어)을 공격했다.

| 관점 | v1의 문제 | v2 결정 |
|---|---|---|
| 마케터: 왜 써야 하나 | 기능만 나열해서 "이미 쓰는 데스크톱 스티키 메모로 충분한데?"에 답하지 못함. 비교 대상이 화면에 없음 | **시청자가 이미 겪는 고통부터** 보여 준다. 화면을 덮은 평범한 스티키 메모 더미, 정작 필요한 한 장을 못 찾는 상황. 특정 제품을 흉내 내지 않고 누구나 아는 노란 종이 메모로 그린다 |
| 마케터: 약속 | 슬로건이 엔드 카드에서야 나옴. 약속이 세 개(적기·모으기·연결하기)로 흩어짐 | 약속 하나: **흩어진 메모가 정리된 계획이 된다**. 모으기 → 찾기 → 잇기 → 끝내기는 이 약속의 증거로만 쓴다 |
| 감독: 스토리 | 갈등·반전 없이 기능 시연만 반복되는 평면 구조 | 3막: 혼돈(문제) → 덩굴 와이프 반전(같은 메모, 다른 세계) → 맑아진 바탕화면(첫 장면과 수미상관) |
| 감독: 프레이밍 | 장면마다 창 하나만 보여서 단편적. 전후 맥락 없음 | 첫 장면과 끝 장면을 **같은 바탕화면, 같은 카메라**로 찍는다. 시청자가 비포·애프터를 직접 비교한다 |
| 게임 디렉터: 재미 | 마스코트는 귀엽지만 목표가 없음(정거장을 순서대로 뛰어다님) | 마스코트에게 목표가 생긴다: 메모 더미에 **깔린다**(개그) → 찾는 메모가 어디 있는지 알지만 꺼내지 못함 → 덩굴로 판을 뒤집음 → 마지막에 맑은 화면에서 쉰다(보상) |
| 기획자: 정직성 | — | 덩굴 와이프는 "가져오기" 기능처럼 보이면 안 된다. 와이프 뒤에 **"같은 메모, MemoIvy에선"**으로 비교임을 밝힌다. 화면 문구와 기능은 Storybook 기준 실제 앱만 쓴다. MIT 오픈소스라 "무료·오픈소스"를 말할 수 있다 |
| 광고: 행동 유도 | 엔드 카드가 짧고 설치 방법만 작음 | 엔드 카드: 아이콘 · MemoIvy · 슬로건 · "Windows·Linux용 무료·오픈소스 메모 앱" · [Microsoft Store] [`snap install memoivy`] · 저장소 주소 |
| 리듬 | 0~3초가 빈 바탕화면이라 훅이 약함 | 0.3초부터 메모가 **철썩** 떨어진다(소리+카메라 펀치). 3초 안에 문제가 읽힌다 |

v1에서 버린 것: 아이콘 탄생 오프닝, 메모 창 타이핑 장(약속 하나에 집중하려고 55초 안에서 덜어냄. 스크린샷과 상세 설명이 다룬다).

## 2. 로그라인과 흐름

메모 더미에 깔린 아이비 잎 '잎새'가 덩굴로 판을 뒤집고, 흩어진 메모를 하나의 계획으로 엮어 바탕화면을 되찾는다.

- 1막 혼돈(0–7.2s): 바탕화면을 메모가 덮고 있다. 세 장이 더 철썩 떨어진다. 잎새가 고개를 내밀자마자 새 메모에 깔린다(개그). 커서가 메모를 이리저리 끌며 '숙소 전화'를 찾지만 실패한다. 잎새는 그 메모가 어디 깔려 있는지 알고 있다.
- 반전(6.6–7.6s): 잎새가 팔을 들고, 그 자리에서 덩굴 도트 와이프가 화면을 덮는다.
- 2막 모으고 찾기(7.2–15s): 같은 메모가 MemoIvy 목록에 색 띠를 달고 정리되어 있다. '숙소'를 검색하면 바로 나온다.
- 3막 잇고 끝내기(15–28s): 캔버스에서 여행 준비 메모에 기차표·숙소 메모를 잇는다. 잎새가 선 끝을 타고 간다. 마지막 할 일을 체크하면 완료 배지가 붙는다.
- 보상(28–36s): 연결선마다 도트 잎이 돋는다. 카메라가 첫 장면과 같은 전체 바탕화면으로 빠지면, 창 하나만 남은 맑은 화면 위에서 잎새가 햇볕을 쬔다.
- 엔드 카드(36–44s).

## 3. 벤치마크

- 배울 것: 생산성 앱 광고의 문제 → 해결 → 보상 3박자, 같은 프레임의 비포·애프터, 화면 녹화형 자동 줌.
- 가져오지 않을 것: 특정 OS 메모 앱의 외형·로고·이름, 타사 캐릭터·음악. phone-alert(오벨) 영상의 서사·샷(엔진 구조만 공유).

## 7. 자막·타이틀

- 하단 프로스티드 알약 자막, `*강조*` 한 군데. 마스코트·논의 대상과 겹치지 않게 아래 레인 예약.
- 자막은 문제 → 약속 → 증거 → 보상 순서로 읽히게 쓴다(film.js `CAPS`).
- 엔드 카드만 타이틀: 아이콘 + MemoIvy + "작은 메모에서, 연결된 생각으로." + "Windows·Linux용 무료·오픈소스 메모 앱" + Microsoft Store·Snap 설치 칩 + 저장소 주소(문구 SSoT: web/main.js END).
- UI 문구는 실제 앱(Storybook `screens-window-states`)과 같다: 메모 검색, 메모 N개, New, 메모 캔버스, 저장됨, 메모 N · 연결 N.
