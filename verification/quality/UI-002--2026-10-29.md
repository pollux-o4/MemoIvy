# UI-002 · 앱 메뉴 아이콘 복구

- 검증: UI-002
- 재현: 설치된 DesktopAppInfo의 `linux-sticky-memo` 테마 아이콘 조회가 실패했다. 사용자 hicolor 캐시는 SVG 설치 이전 시각이었다.
- 수정: desktop 템플릿의 Icon을 HOME 치환으로 설치된 SVG 절대 경로에 연결했다. 현재 설치 메뉴도 동일하게 갱신했다.
- 검사: `dbus-run-session -- python3 tools/ui_002_app_icon.py`
  - 수정 전: 아이콘 조회 실패.
  - 수정 후: 현재 테마에서 SVG 조회·로드 통과.
- 환경: Yaru-prussiangreen-dark, GTK3 icon lookup, 설치된 앱 메뉴 항목.
- 미검증: GNOME Shell 검색 패널의 실제 화면 재확인.
