# 데스크톱 라이브러리 배치 시안

`python3 -m http.server 8765 --directory prototypes/library-bento`

http://localhost:8765 또는 index.html 직접 열기.

현재 MemoIvy의 창 컨트롤·검색·보기 전환·색 띠·진행률·중첩 메모 카드를 재현했다. 넓은 창은 프로젝트 묶음을 여러 열에 배치하고, 좁은 창은 한 열로 표시한다. 화살표·모두 펼치기·검색·최근 보기·메모 열기·밝은 테마를 조작할 수 있다. 하단 도구는 시안 비교용이다.

합성 데이터와 메모리 상태만 사용한다. 네이티브 GTK 렌더링·창 관리·실제 저장·캔버스는 연결하지 않은 폐기 가능한 시안이다. 기존 ?variant 파라미터는 사용하지 않는다.
