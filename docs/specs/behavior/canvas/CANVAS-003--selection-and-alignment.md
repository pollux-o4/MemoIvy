# CANVAS-003 · 다중 선택·정렬·맞춤선

- 범위: 캔버스 카드 묶음의 선택과 배치 도구. 저장 필드는 위치뿐이며 저장 형식을 바꾸지 않는다. 근거는 사용자 요청이며 실제 사용자 관찰 자료는 없다.

## 선택

- 빈 곳 끌기: 범위와 겹치는 카드 선택. Shift를 누르면 기존 선택에 더한다.
- Shift+누르기: 선택 토글. Ctrl+A: 모두 선택. Esc 또는 빈 곳 누르기: 해제.
- 2개 이상 선택하면 정렬 막대를 표시하고 단일 메모 패널은 숨긴다.

## 정렬

| 동작 | 입력 | 기준 |
|---|---|---|
| 왼쪽·가로 가운데·오른쪽 맞춤 | Alt+A / H / D | 선택 영역 경계. 다른 축 유지. 2개 이상 |
| 위쪽·세로 가운데·아래쪽 맞춤 | Alt+W / V / S | 위와 같음 |
| 가로·세로 간격 같게 | Alt+Shift+H / V | 양 끝 고정. 3개 이상 |
| 격자로 정리 | Alt+T | 현재 줄·칸 순서 유지, 왼쪽 위 고정 |
| 연결 순서로 배치 | Alt+F | 연결 방향이 왼쪽→오른쪽. 순환은 되돌아가는 연결을 무시. 선택 밖 연결 무시. 선택이 없으면 전체 |

## 끌기·연결

- 끌기는 선택 전체를 함께 옮기고 상대 위치를 유지한다. 허용 좌표를 넘으면 묶음 전체의 이동량을 제한한다.
- 맞춤선: 다른 카드의 가장자리·중심과 화면 6px 안이면 맞추고 축마다 안내선 하나를 보인다. Ctrl: 맞춤 끄기. Shift: 한 축으로 제한. Esc: 끌기 취소·제자리 복귀.
- 포인터가 보드 가장자리에 닿으면 끌기 중 보드가 함께 이동한다.
- 카드 오른쪽 연결 점을 다른 카드로 끌면 연결한다. 자기·중복 대상은 강조하지 않고 연결하지 않는다.

## 복구·완료 기준

- 정렬·이동·연결은 각각 한 번의 Ctrl+Z로 복구하고 Ctrl+Shift+Z·Ctrl+Y로 다시 실행한다. 변화가 없는 조작은 되돌리기 기록과 저장 요청을 만들지 않는다.
- 완료 기준: `canvas_003` 규칙 검사, 위젯 검사의 정렬·되돌리기·동일 위젯 유지, canvas_001_ui_smoke의 범위 선택·정렬·되돌리기·연결 점 끌기.
