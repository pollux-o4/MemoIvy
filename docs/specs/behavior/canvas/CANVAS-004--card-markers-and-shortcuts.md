# CANVAS-004 · 카드 표식과 보드 단축키

## 카드 미리보기

- 카드·선택 패널은 메모의 체크·기호·번호를 잃지 않고 표시한다. 읽기 전용이며 눌러도 원문을 바꾸지 않는다. 체크 변경은 원본 메모에서 한다.
- 첫 줄이 목록 항목이면 제목 앞에 표식을 함께 보인다. 완료 항목은 취소선으로 표시한다.
- 줄 예산: 카드 3줄, 패널 5줄. 항목은 한 줄씩이고 연속 문단은 합쳐 남은 줄까지 줄바꿈한다. 담지 못한 내용은 카드 아래에 `외 N줄`로 표시한다.
- 낮은 배율에서는 기존 미리보기 생략 규칙을 따른다. 위젯은 표시 행만큼만 만들고 재사용한다.

## 단축키

| 키 | 동작 | 조건 |
|---|---|---|
| Delete, Backspace | 선택한 메모 삭제 확인 | 선택 있음, 끌기 중·저장 작업 중 아님 |
| Ctrl+Enter | 선택 전체 완료 전환 | 하나라도 미완료면 모두 완료 |
| Ctrl+L | 다음 메모 연결 목록 열기 | 단일 선택, 후보 있음 |

- 삭제는 복구할 수 없어 NOTE-002 확인창을 거친다. 메모 하나면 제목을 보이고 여러 개면 개수를 보인다. 패널의 삭제 항목과 다중 선택 막대의 삭제 버튼도 같은 경로다.
- 여러 개 삭제는 앞선 삭제 저장이 끝나면 다음을 시작한다. 저장에 실패하면 남은 삭제를 멈추고 메모를 유지한다. 이미 삭제된 메모는 복구하지 않는다.
- 팝오버에 포커스가 있으면 팝오버가 키를 우선 처리한다(KEY-001). 완료 전환은 되돌리기 대상이고 삭제는 대상이 아니다(CANVAS-001).
