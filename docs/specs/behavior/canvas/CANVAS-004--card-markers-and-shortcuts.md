# CANVAS-004 · 카드 표식과 보드 단축키

## 카드 미리보기

- 카드·선택 패널은 메모의 체크·기호·번호를 잃지 않고 표시한다. 읽기 전용이며 눌러도 원문을 바꾸지 않는다. 체크 변경은 원본 메모에서 한다.
- 첫 줄이 목록 항목이면 제목 앞에 표식을 함께 보인다. 완료 항목은 취소선으로 표시한다.
- 줄 예산: 카드 3줄, 패널 5줄. 항목은 한 줄씩이고 연속 문단은 합쳐 남은 줄까지 줄바꿈한다. 담지 못한 내용은 카드 아래에 `외 N줄`로 표시한다.
- 낮은 배율에서는 기존 미리보기 생략 규칙을 따른다. 위젯은 표시 행만큼만 만들고 재사용한다.

## 단축키

| 키 | 동작 | 조건 |
|---|---|---|
| Delete, Backspace | 선택한 메모 삭제 확인 | 선택 있음, 끌기 중·저장 작업 중 아님 |
| Ctrl+Enter | 선택 전체 완료 전환 | 하나라도 미완료면 모두 완료 |
| Ctrl+L | 다음 메모 연결 목록 열기 | 단일 선택, 후보 있음 |
| Ctrl+C | 선택 복사 | 선택 있음, 입력 칸 밖 |
| Ctrl+X | 선택 복사 후 삭제 확인 | 선택 있음, 입력 칸 밖 |
| Ctrl+V | 붙여넣기 | 입력 칸 밖 |
| Ctrl+D | 선택 복제 | 선택 있음, 입력 칸 밖 |
| F2 | 드로어 이름 칸으로 이동 | 단일 선택 |
| 오른쪽 클릭, Shift+F10, 메뉴 키 | 카드 메뉴 | 선택 있음 |

- 삭제는 복구할 수 없어 NOTE-002 확인창을 거친다. 메모 하나면 제목을 보이고 여러 개면 개수를 보인다. 패널의 삭제 항목과 다중 선택 막대의 삭제 버튼도 같은 경로다.
- 여러 개 삭제는 앞선 삭제 저장이 끝나면 다음을 시작한다. 저장에 실패하면 남은 삭제를 멈추고 메모를 유지한다. 이미 삭제된 메모는 복구하지 않는다.
- 복사는 내용·색·완료·상대 위치·선택 안끼리의 연결을 담고, 본문을 평문으로 시스템 클립보드에도 쓴다. 붙여넣기는 현재 범위에 24px씩 비껴 놓고 새 메모를 선택한다. 그 뒤 다른 앱에서 복사한 글이 있으면 그 글로 새 메모를 만든다. 프로젝트는 하위 메모 없이 복사한다. 붙여넣기·복제는 되돌리기 대상이 아니다.
- 드로어는 위에서 아래로 이름·소개(프로젝트) → 상태·주 동작(들어가기·열기) → 연결 → 정리 → 삭제 순서다. 이름·소개는 입력 중 실시간 저장하고, 포커스를 잃거나 Enter(소개는 Ctrl+Enter)에 마치며 Esc로 되돌린다. 첫 줄이 이름, 나머지가 소개다. 소개는 메모 편집기와 같은 Markdown 편집(목록 이어쓰기·체크박스·서식 단축키)이고, 카드 미리보기는 줄바꿈을 줄 단위로 유지한다.
- 프로젝트 설명의 전체 편집은 메모 편집기가 원본 경로다(목록형 제목 클릭과 같음). 캔버스에서는 드로어 머리의 '메모로 열기'·카드 메뉴·Shift+Enter로 연다. 주 동작(Enter·두 번 누르기)은 들어가기로 유지한다.
- 카드 메뉴는 열기·메모로 열기(프로젝트)·이름 편집(단일 선택일 때)·색·완료·복사·복제·삭제 순서다. 여러 장을 선택했으면 선택 전체에 적용한다.
- 팝오버에 포커스가 있으면 팝오버가 키를 우선 처리한다(KEY-001). 완료 전환은 되돌리기 대상이고 삭제는 대상이 아니다(CANVAS-001).
