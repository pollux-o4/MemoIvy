# CANVAS-005 · 마인드맵 가지와 연결 조작

## 범위·입력

- 웹·데스크톱 캔버스에서 카드 사이의 가지(방향 연결)를 만드는 조작을 정한다. 연결 저장·해제·순환 규칙은 CANVAS-001을 따른다.
- 가지 손잡이는 카드 오른쪽 가운데에 있으며, 카드에 포인터를 올리거나 카드를 선택한 경우에만 표시한다.
- 입력 수단은 손잡이 끌기, 손잡이 누르기, 키보드(Tab·Enter, 손잡이에서 Enter·Space)로 한다.

## 기대 동작

- 끌기: 포인터가 3px을 넘게 움직이면 끌기로 판정하고 미리보기 선을 표시한다. 다른 카드 위에서 놓으면 연결하고, 빈 곳에서 놓으면 그 자리에 하위 메모를 만들어 연결한다.
- 누르기: 즉시 메모를 만들지 않고 연결 대상 고르기 상태로 들어간다. 이 상태에서는 안내 문구와 십자 커서를 표시하고 미리보기 선이 포인터를 따라간다.
  - 다음 누르기가 다른 카드이면 연결하고, 빈 곳이면 그 자리에 하위 메모를 만들어 연결한다.
  - 출발 카드를 다시 누르거나 Esc를 누르면 아무것도 바꾸지 않고 종료한다.
  - 고르기 상태의 누르기는 카드 끌기·선택보다 우선한다.
- 키보드: 고를 포인터가 없으므로 Tab과 손잡이의 Enter·Space는 하위 메모를 즉시 만들고, Enter는 같은 부모의 형제 메모를 만든다. 새 메모는 선택되고 이름 칸에 포커스가 간다.
- 곡선 연결선의 휘는 정도는 각 연결점이 향하는 방향으로 남은 거리에 맞춘다. 두 카드가 가로로 가깝고 세로로 멀어도 선이 꺾였다 돌아오지 않아야 한다.

## 실패·복구

- 새 메모의 위치는 저장 가능한 좌표 범위(DATA-001)로 맞춘다. 범위 밖 좌표 때문에 연결 변경이 함께 거절되어서는 안 된다.
- 만들기·연결은 캔버스 되돌리기로 복구한다(CANVAS-001).

## 완료 기준

- 누르기만으로는 메모 수가 변하지 않고, 고르기 결과에 따라 연결만 늘거나 메모와 연결이 함께 늘어난다.
- 끌기 중에만 미리보기 선이 보이고, 놓은 뒤에는 사라진다.
- 검증: e2e `캔버스 마우스 가지`·`캔버스 손잡이 누르기`, 단위 테스트 `paths`·`align`(savedPoint).
