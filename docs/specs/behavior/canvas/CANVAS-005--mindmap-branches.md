# CANVAS-005 · 마인드맵 가지와 연결 조작

## 범위·입력

- 이 명세는 웹·데스크톱 캔버스에서 카드 사이에 가지(방향 연결)를 만드는 조작을 정한다. 연결 저장·해제·순환 규칙은 CANVAS-001을 따른다.
- 가지 손잡이는 카드 오른쪽 가운데에 두며, 카드에 포인터를 올리거나 카드를 선택한 경우에만 표시한다.
- 입력 방법은 손잡이 끌기, 손잡이 누르기, 키보드(Tab·Enter, 손잡이에서 Enter·Space)의 세 가지로 한다.

## 기대 동작

- 끌기: 포인터가 3px을 넘게 움직이면 끌기로 판정하고 미리보기 선을 표시한다. 다른 카드 위에서 놓으면 연결하고, 빈 곳에서 놓으면 그 자리에 하위 메모를 만들어 연결한다.
- 누르기: 메모를 바로 만들지 않고 연결 대상 지정 상태로 전환한다. 이 상태에서는 안내 문구와 십자 모양 커서를 표시하며, 미리보기 선이 포인터를 따라 움직인다.
  - 이어서 다른 카드를 누르면 연결하고, 빈 곳을 누르면 그 자리에 하위 메모를 만들어 연결한다.
  - 출발 카드를 다시 누르거나 Esc를 누르면 변경 없이 지정 상태를 끝낸다.
  - 지정 상태에서 누른 입력은 카드 끌기·선택보다 먼저 처리한다.
- 키보드: 키보드로는 연결 대상을 고를 수 없으므로 Tab과 손잡이에서의 Enter·Space는 하위 메모를 바로 만들고, Enter는 같은 부모 아래에 형제 메모를 만든다. 새로 만든 메모는 선택 상태로 두고 이름 칸으로 포커스를 옮긴다.
- 곡선 연결선의 굽은 정도는 각 연결점이 향하는 방향의 남은 거리를 기준으로 정한다. 두 카드의 가로 간격이 좁고 세로 간격이 넓은 경우에도 선이 꺾였다가 되돌아오는 모양이 생기지 않도록 한다.

- 카드 표면은 가지 초점으로 흐려진 상태에서도 연결선을 가린다. 화살촉은 대상 카드의 펼친 미리보기와 프로젝트 종이 더미 바깥에 둔다.
- 가지 개요에서 같은 단계 순서를 Alt+↑·↓로 바꾼다. 다른 항목의 위·아래에 끌어 놓으면 해당 항목의 앞·뒤 형제로 옮긴다. 뿌리 옆이나 자기 가지 안으로는 옮기지 않는다. 여러 곳에서 들어오는 연결 중 개요에 표시된 부모 이외의 출발 카드는 별도 목록에 표시한다.

## 실패 대응·복구

- 새 메모의 위치는 저장 가능한 좌표 범위(DATA-001) 안으로 조정한다. 범위를 벗어난 좌표로 인하여 함께 저장하는 연결 변경까지 거부되지 않도록 한다.
- 가지 연결과 배치는 캔버스 되돌리기로 복구한다. 이미 만든 메모는 보존한다(CANVAS-001).

## 완료 기준

- 손잡이를 누르기만 해서는 메모 수가 바뀌지 않으며, 지정 결과에 따라 연결만 늘어나거나 메모와 연결이 함께 늘어난다.
- 미리보기 선은 끄는 동안에만 표시하고, 놓은 뒤에는 지운다.
- 검증: e2e `캔버스 마우스 가지`·`캔버스 연결선`, 단위 테스트 `paths`·`align`(savedPoint)·`outline_edit`·`outline_tree`.
