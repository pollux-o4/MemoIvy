# CANVAS-001 · 메모 캔버스

## 범위·입력

- 사용자 목표: 스티키 메모를 공간에 배치하고 방향 관계와 진행 흐름을 이해한다. 근거는 이번 사용자 요청이며 실제 사용자 관찰 자료는 없다.
- 목록·편집기의 캔버스 버튼으로 진입한다. 메모 하나는 동일 UUID의 카드 하나이며 내용·색상은 원본 메모를 사용한다.
- 공유 캔버스 하나에서 스크롤·Space 끌기 탐색, 확대·축소·전체 보기, 카드 끌기·방향키 이동, 다음 메모 선택·연결 점 끌기·연결 해제, 완료·신호 전송을 제공한다. 다중 선택·정렬은 CANVAS-003.
- 캔버스는 한 단계(최상위 또는 프로젝트)씩 보여 준다. 단계·묶기·길 안내는 PROJECT-001.
- 카드 누르기는 선택, 두 번 누르기·Enter는 원본 메모 열기다(프로젝트 카드는 들어가기). 카드에는 서식 기호를 뺀 제목·미리보기와 연결·할 일 수를 표시한다. 목록 표식과 삭제·완료·연결 단축키는 CANVAS-004.

## 상태·복구

- 빈 화면은 새 메모 작성 경로를 안내한다. 선택 전에는 보드만 보이고 사용법은 독의 도움말에 둔다. 단일 선택 시 떠 있는 패널에 원본 열기·완료·신호·다음/이전 메모를 표시한다. 새 메모가 만들어지면 선택하고 보이는 곳으로 이동한다.
- 완료는 연결된 다음 메모에 일회성 신호를 보낸다. 신호 보내기는 상태를 바꾸지 않는 재생이다. 다음 메모 자동 완료·외부 자동 실행은 없다.
- 모션 정책은 CANVAS-002를 따른다. 모션 줄이기에서는 정적 도착 표시를 사용한다.
- 배치·연결·완료 변경은 세션 내 되돌리기·다시 실행으로 복구한다. 원문·색상·메모 생성/삭제에는 이 되돌리기를 적용하지 않는다. 삭제는 확인을 거친다. 삭제된 메모를 되살리거나 삭제된 대상 연결을 복원하지 않는다.
- 생성/삭제 저장 중 캔버스 변경을 차단한다. 메모 삭제는 모든 입출력 연결을 같은 저장 스냅샷에서 제거한다.
- 독에 저장 중·저장됨·실패를 표시한다. 실패 시 메모리 내용을 유지하고 독을 강조해 다시 시도를 제공한다. 창 닫기는 저장을 요청하고 목록으로 돌아간다. 종료 저장 경계는 SAVE-001·SAVE-002를 따른다.

## 완료 기준

- 기존 형식 메모를 잃지 않고 로드하며 재시작 후 카드 위치·연결·완료 상태를 복원한다.
- 메모 본문·색상 수정은 목록과 카드에 반영하고 중복 메모를 만들지 않는다. 카드 위젯은 메모별로 유지한다.
- 확대된 카드에서도 선 끝점과 카드 테두리가 맞고 드래그가 확대 배율에 따라 동작한다.
- 연결 해제는 메모를 보존한다. 자기·중복·존재하지 않는 대상 연결을 거부한다. 순환 관계는 허용하되 신호는 직계 다음 메모까지만 이동한다.
- 키보드 Tab으로 카드·연결·완료 조작에 접근하고 방향키로 선택 위치를 변경한다. Shift+방향키는 큰 간격 이동이다. Tab은 화면 밖 카드를 포함해 읽는 순서로 이동하고, 옮겨 간 카드가 패널·창 밖에 있으면 보이는 곳으로 이동한다. 마지막 카드 다음은 도구 막대다. 숨겨진 컨트롤에는 포커스를 남기거나 돌려주지 않는다(FOCUS-001).
- 밝은/어두운 테마·좁은 창·긴 제목·빈 메모·분기와 순환·저장 실패를 합성 데이터로 검증한다. 실제 사용자 연구·Wayland/IME 검증과 구분한다.
