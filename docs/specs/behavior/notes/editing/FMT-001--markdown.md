# FMT-001 · 메모 실시간 서식

- 입력·표시: 단일 편집 화면에 `#`·`##`, 굵게·기울임·취소선, 글머리표·번호 목록, 체크 목록, 링크를 표시한다. 완료 항목의 Shift+Enter 이어쓰기 줄에도 취소선을 적용한다. 목록 정렬과 링크 미리보기는 FMT-003, 첨부 이미지 줄은 FMT-004. GTK는 커서·선택이 닿는 줄의 인라인 문법을 드러낸다. Electron은 커서·선택이 닿는 인라인 서식 범위의 기호만 드러낸다. 목록 표식은 FMT-003대로 커서 줄에서도 렌더링한다. 기본 화면에는 편집 도구 줄을 두지 않는다. 원문 보기·서식 도움말은 더보기 메뉴에 두며 Ctrl+Shift+M으로 원문을 전환한다. 원문 모드는 전체 문법을 보여준다. 미완성·지원 밖 문법은 원문으로 남긴다.
- Electron 실시간 보기: 인라인 코드와 백틱 코드 블록을 본문과 구분되는 배경으로 표시한다. 코드 블록 안을 편집할 때 여는 백틱과 닫는 백틱을 함께 표시한다. 블록을 벗어나거나 편집기 포커스를 잃으면 둘을 숨기고 백틱만 있던 줄을 접는다. 닫는 백틱이 없는 여는 줄 끝에서 Enter를 누르면 닫는 백틱을 넣고 커서를 블록 안에 둔다. Storybook Markdown / Editor에서 한글 본문·인라인 코드·여러 줄 코드 블록을 비교한다.
- 편집: 표시 갱신은 본문·커서·선택·undo를 바꾸지 않는다. 한글 조합 중 레이아웃 갱신을 보류하고 확정 후 반영한다. 파싱 변경은 idle에서 병합하고 커서 이동에는 파싱 결과를 재사용한다.
- 동작: 네이티브 체크박스 클릭 또는 해당 줄에서 Ctrl+Enter로 완료(`[x]`)를 켜고 끈다. Shift+클릭은 진행 중(`[/]`, 반쯤 채운 상자)을 켜고 끈다. 진행 중에서 클릭하면 완료가 된다. 진행 중은 완료 집계에 넣지 않는다. 바꿈은 한 번의 undo로 복구한다. 일반 링크 클릭은 편집, Ctrl+클릭·미리보기 카드는 http·https·mailto 링크 열기다. HTML·실행 스킴을 실행하지 않는다. 저장·닫기 잠금 중 체크 편집도 차단한다.
- 데이터·복구: Note.text의 원문이 저장·검색의 원본이다. 전체 선택·복사는 숨겼던 문법을 포함한다. 정상 닫기·실패 복구는 SAVE-001·SAVE-002를 따른다.
- 완료 기준: fmt_001의 문자 범위·미완성·네이티브 위젯·조합 신호·undo 검사, 실제 앱의 입력·선택·삭제·체크·링크·창 크기 변경·원문 저장 후 재열기. Electron은 Chromium 조합 입력으로 이미지 줄의 미리보기 갱신·후속 입력·자동저장을 검증한다. 실제 OS IME 엔진과 조합 신호 재현 검증은 구분한다.
