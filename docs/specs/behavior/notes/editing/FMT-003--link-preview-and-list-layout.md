# FMT-003 · 링크 미리보기와 목록 표시·입력

## 링크 미리보기

- 대상: inline 링크, `<주소>`, 본문의 http·https 주소. 주소는 공백·비ASCII·`<>"` 앞에서 끝나고 끝의 문장부호를 뺀다. 코드·이미지·HTML 안은 링크로 보지 않는다.
- 표시: 링크 위에 350ms 머물면 카드를 띄운다. 키보드는 커서가 링크 안에 600ms 머물면 띄운다. 카드가 떠 있거나 방금 닫혔으면 옆 링크로 60ms 만에 옮겨 간다. 입력 중·조합 중·끌기 중에는 띄우지 않으며 입력 후에는 포인터가 실제로 움직여야 다시 뜬다.
- 내용: 이름, 호스트를 강조한 실제 주소, 경고, 열기·주소 복사·주소 수정. 네트워크 요청과 외부 내용 표시는 하지 않는다.
- 경고: 평문 http, 빈 호스트, 주소의 사용자 정보, 이름과 다른 도메인, 비ASCII·punycode 호스트·보이지 않는 문자. 이름은 주소 표기(`https://`, `www.`)이거나 흔한 웹 도메인일 때만 도메인으로 보아 `Node.js`·`README.md`에 경고하지 않는다. 보이지 않는 문자는 대체 문자로 드러낸다.
- 닫기: 벗어나면 220ms 뒤 닫혀 카드로 포인터를 옮길 수 있다. 카드 위에서는 유지한다. Esc·입력·스크롤·창 폭 변경·포커스 상실·원문 전환·창 숨김은 바로 닫는다. Esc로 닫은 링크는 벗어났다 돌아와야 다시 뜬다. 카드는 포커스를 가져가지 않는다.
- 동작: 일반 클릭은 편집이고 Ctrl+클릭·Ctrl+Enter(체크 항목이 아닌 줄)·열기 버튼이 링크를 연다. Ctrl을 누른 채 링크 위에 있으면 포인터 모양이 바뀐다. 복사는 카드를 유지한 채 확인 문구를 보인다. 주소 수정은 원문의 주소만 선택한다.
- 모션: 등장은 기존 메뉴와 같은 확대·페이드, 퇴장은 90ms 페이드. 모션 줄이기에서는 전환 없이 표시·제거한다.

## 목록 표시·입력

- 인식: 줄 단위로 `- `·`* `·`+ `·`- [ ] `·`1. `·`1) `를 치는 즉시 표식이 된다. 문단 바로 뒤와 본문 없는 항목도 포함한다. 공백을 치기 전(`-`, `-5도`)은 표식이 아니다. 코드 블록·구분선·인용문은 제외한다.
- 표시: 커서가 있는 줄도 항상 표식으로 보인다. 기호는 깊이별 표식, 체크는 네이티브 체크박스, 번호는 원문 글자를 흐리게 쓴다. 본문과 줄바꿈된 줄은 표식 칸 뒤로 정렬하며 한 단계는 24px이다. 카드·패널 요약에서도 이어쓰기 줄은 같은 단계와 본문 시작점에 맞춘다. 완료 항목 본문은 흐리게 취소선으로 표시한다. 인라인 서식은 FMT-001대로 커서 줄에서 드러난다.
- 원문 확인: 표식 문법은 원문 보기에서만 보여 준다. 선택 중에도 표식을 유지하고 복사는 항상 원문이다. 인용문 안, 번호와 체크를 함께 쓴 항목(`1. [ ] 일`)은 원문으로 두고 체크 변경은 괄호 클릭·Ctrl+Enter로 한다.
- 커서: 체크박스 위는 화살표, 편집 본문은 텍스트 커서다. 표식은 한 글자처럼 다룬다. 표식 안으로 들어가면 본문 앞으로 옮기고, 본문 앞의 왼쪽 키는 앞 줄 끝으로 간다.
- Enter: 다음 항목을 잇는다. 기호·들여쓰기를 유지하고 체크는 비우며 번호는 하나 늘리고 이어지는 같은 단계 번호를 민다. 빈 항목에서는 한 단계 내어 쓰고, 최상위면 목록을 끝낸다.
- Shift+Enter: 현재 목록 항목에 속한 이어쓰기 줄을 만든다. 원문에는 목록 본문 들여쓰기 폭만큼 들여쓰고, 화면에서는 같은 항목 본문 시작점에 맞춘다.
- Backspace(본문 앞): 들여쓴 항목은 내어 쓰고 최상위는 표식을 지워 평문으로 만든다. Delete(앞 줄 끝): 표식까지 지워 본문만 잇는다.
- Tab·Shift+Tab: 항목을 들여 쓰거나 내어 쓴다. 선택 범위의 항목 전체에 적용한다. 항목이 아닌 줄은 기존 동작이다.
- 위 편집은 각각 한 번의 undo로 되돌린다. 한글 조합 중에는 미완성 입력으로 목록 구조를 다시 그리지 않고, 확정 뒤 표식과 배치를 동기화한다. 조합 중 Enter는 입력기에 맡기고 확정 뒤 표식을 채운다. 저장 원문은 Markdown 그대로다(FMT-001).
