# FMT-004 · 메모 이미지

- 범위: 편집 창의 이미지 붙여넣기·끌어 놓기·표시·크기 조절·크게 보기·메모에서 빼기. 저장·참조 형식은 DATA-003, 파일 관리는 FILE-001.
- 넣기
  - Ctrl+V에서 클립보드에 텍스트가 없고 이미지가 있으면 PNG로 저장한다. 파일 관리자에서 끌어 놓은 이미지 파일은 원본 바이트를 복사한다. 원본 경로는 기록하지 않는다.
  - 커서 줄(끌어 놓기는 놓은 높이의 줄)이 비어 있지 않으면 다음 줄에 넣고, 참조 줄 뒤에 빈 줄을 하나 둬 이어서 쓸 수 있게 한다. 여러 장은 순서대로 한 줄씩 넣는다. 넣기는 한 번의 undo로 되돌린다.
  - 끌어 놓기는 가로 위치와 무관하게 놓은 높이의 줄을 기준으로 한다. 줄 끝 너머·들여쓴 빈 곳에 놓아도 맨 끝으로 가지 않는다.
  - 목록 항목 줄에 넣으면 그 항목 본문 들여쓰기로 이어쓰기 줄을 만들고 뒤 빈 줄은 두지 않는다. 목록 구조·번호가 끊기지 않으며 이미지는 항목 본문 시작에 맞춰 그린다.
  - 거부(형식·크기·쓰기 실패)는 상태 줄에 이유를 보이고 본문을 바꾸지 않는다.
- 표시
  - 참조 줄만 이미지로 그린다. 커서가 그 줄에 없으면 원문은 커서 자리만 남기고 숨기며, 커서가 들어오면 흐린 작은 글자로 원문을 드러낸다. 원문 보기는 이미지 없이 전체 문법을 보인다.
  - 너비가 없으면 원래 크기와 본문 폭 중 작은 쪽, 있으면 그 값을 본문 폭 안에서 쓴다. 높이는 비율로 정한다. 모서리는 8px 둥글게 한다.
  - 파일이 없거나 읽을 수 없으면 원문을 지우지 않고 "이미지를 찾을 수 없음" 자리 표시를 그린다. 큰 이미지는 화면 밖 스레드에서 읽는다.
- 조작 (마우스를 올리면 나타남)
  - 오른쪽 아래 모서리 핸들: 비율을 유지하며 64px~본문 폭 사이로 끈다. 끄는 동안은 화면만 바뀌고 놓을 때 `|너비`를 한 번 고쳐 쓴다(undo 한 번). 핸들 더블클릭은 너비를 지워 원래 크기로 돌린다.
  - 크게 보기: 위쪽 도구의 확대 버튼 또는 이미지 더블클릭. 화면 맞춤과 원래 크기를 클릭으로 전환하고 Esc·바깥 클릭·닫기 버튼으로 닫는다.
  - 옮기기: 이미지를 끌면 원래 자리는 흐려지고 넣을 자리에 강조색 가로선이 나타난다. 같은 메모에 놓으면 줄을 옮기고(넣기 규칙과 같은 자리·들여쓰기) 한 번의 undo로 되돌린다. 자기 줄에 놓으면 바뀌지 않는다. 다른 메모에 놓으면 그 메모에 복사된다.
  - 메모에서 빼기: 도구의 휴지통 버튼. 참조 줄을 지우고 undo로 되돌린다. 파일은 지우지 않는다(FILE-001).
  - 읽기 전용(저장·닫기 잠금) 동안 크기 조절·빼기는 막고 크게 보기는 허용한다.
- 모션 (CANVAS-002 원칙을 따른다)
  - 도구·핸들은 140ms 페이드, 이미지 호버는 그림자 깊이만 바꾼다. 크게 보기는 0.96 배율에서 펴지는 200ms 감속 등장, 120ms 페이드 퇴장.
  - 크기 조절은 포인터를 바로 따르고 프레임당 한 번만 배치한다. 모션 줄이기에서는 전환 없이 바로 바뀐다.
- 접근성: 이미지에 설명(alt)을 접근성 이름으로 준다. 없으면 "이미지". 도구 버튼은 툴팁과 이름을 가진다.
- 완료 기준: fmt_004 단위 테스트로 참조 줄 인식·너비 범위·문법 생성, 위젯 테스트로 붙여넣기 삽입 위치·undo·크기 조절 기록·빼기·자리 표시, 목록 안 넣기의 들여쓰기·구조 유지, 같은 메모 안 옮기기와 undo를 확인한다. 실제 앱에서 스크린샷 붙여넣기·끌어 놓기·크게 보기를 확인한다.
