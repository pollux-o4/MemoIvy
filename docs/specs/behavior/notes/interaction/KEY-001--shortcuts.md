# KEY-001 · 키보드 조작

- 앱 창: Ctrl+N 새 메모, Ctrl+F 목록 검색·검색어 선택, Ctrl+W 현재 창 정상 닫기, F1 단축키 안내. 새 메모·닫기는 기존 저장·실패 복구 경로를 사용한다.
- 편집(FMT-002): Ctrl+B 굵게, Ctrl+I 기울임, Ctrl+U 밑줄(터미널식 줄 삭제 대신 문서 편집기 관례를 따른다), Ctrl+Shift+X 취소선, Ctrl+K 링크(URL 선택), Ctrl+1/2 제목·소제목, Ctrl+Shift+7/8/9 번호·글머리·체크 목록.
- 편집 계약: 선택 영역 또는 현재 줄에 적용하고 같은 서식은 해제한다. 한 번의 undo로 복구하며 편집 잠금·조합 중에는 서식 변경을 적용하지 않는다. Ctrl+Enter 체크 변경(체크 항목이 아닌 줄에서는 커서 아래 링크 열기), Ctrl+Shift+M 원문 전환은 유지한다.
- 캔버스: 선택·보기 키는 CANVAS-001·CANVAS-002, 정렬 키는 CANVAS-003, 삭제·완료·연결 키는 CANVAS-004, 가지 키(Tab·Enter)는 CANVAS-005. 입력 위젯·팝오버에 포커스가 있으면 그 위젯이 키를 우선 처리한다.
- 안내: 메모 더보기 메뉴의 단축키·서식 도움말 항목과 F1로 현재 앱 창 안에 도움말을 연다. 캔버스 독에서는 캔버스 주제로 시작한다. 도움말은 창보다 작게 표시하고 본문만 스크롤한다. 기본 동작 그림의 재생 표시와 안내 문구는 마우스로 재생할 수 있음을 알린다. 포인터를 올린 항목만 재생하고, 모션 줄이기 설정에서는 그림을 정지하고 재생 안내를 숨긴다. Esc 또는 닫기 단추로 원래 화면에 돌아간다. 탭 위 검색창은 두 주제의 동작·키·서식을 함께 검색하며 결과에 주제를 표시한다. 검색어를 지우면 보던 탭으로 돌아간다. 검색과 탭 전환 중 검색창과 대화상자의 위치·크기를 유지하고 본문만 짧게 전환한다. 도움말은 동작마다 키를 한 줄씩 보이고 서식 줄에는 Markdown 입력 문법을 함께 보인다. 새 메모·검색·캔버스 도구 tooltip에 해당 키를 표시한다.
- 검증은 Electron E2E의 ‘메모 작성’과 ‘캔버스 연결선’을 사용한다. 같은 창의 도움말, 좁은 창의 여백, 포인터 진입·이탈, 모션 줄이기, 통합 검색과 탭 복원, Esc와 포커스 복원을 확인한다.
