# FMT-001 · 메모 실시간 서식

- 입력·표시: 단일 편집 화면에 `#`·`##`, 굵게·기울임·취소선, 글머리표·번호 목록, 체크 목록, inline 링크를 표시한다. 커서·선택이 닿는 줄의 문법을 드러내고 나머지 지원 문법은 숨긴다. 기본 화면에는 편집 도구 줄을 두지 않는다. 원문 보기·서식 도움말은 더보기 메뉴에 두며 Ctrl+Shift+M으로 원문을 전환한다. 원문 모드는 전체 문법을 보여준다. 미완성·지원 밖 문법은 원문으로 남긴다.
- 편집: 표시 갱신은 본문·커서·선택·undo를 바꾸지 않는다. 한글 조합 중 레이아웃 갱신을 보류하고 확정 후 반영한다. 파싱 변경은 idle에서 병합하고 커서 이동에는 파싱 결과를 재사용한다.
- 동작: 네이티브 체크박스 클릭 또는 해당 줄에서 Ctrl+Enter로 `[ ]`·`[x]`를 바꾸며 한 번의 undo로 복구한다. 일반 링크 클릭은 편집, Ctrl+클릭은 http·https·mailto 링크 열기다. HTML·실행 스킴을 실행하지 않는다. 저장·닫기 잠금 중 체크 편집도 차단한다.
- 데이터·복구: Note.text의 원문이 저장·검색의 원본이다. 전체 선택·복사는 숨겼던 문법을 포함한다. 정상 닫기·실패 복구는 SAVE-001·SAVE-002를 따른다.
- 완료 기준: fmt_001의 문자 범위·미완성·네이티브 위젯·조합 신호·undo 검사, 실제 앱의 입력·선택·삭제·체크·링크·창 크기 변경·원문 저장 후 재열기. 실제 IME 엔진과 조합 신호 재현 검증은 구분한다.
