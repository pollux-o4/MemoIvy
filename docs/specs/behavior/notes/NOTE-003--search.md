# NOTE-003 · 제목 우선 검색

- 입력: 목록 검색창의 문자열.
- 계약
  - 검색어와 본문을 소문자로 변환한 뒤 부분 문자열 일치로 필터링한다.
  - 제목은 카드에 표시되는 첫 번째 비어 있지 않은 줄이다. 제목에 검색어가 포함된 결과를 본문에만 포함된 결과보다 먼저 표시한다. 각 그룹 안에서는 수정 시각 내림차순이다.
  - 빈 검색어는 ‘최근’ 보기에서 전체 목록을 수정 시각 내림차순으로 표시한다. 기본 ‘프로젝트별’ 보기와 검색 결과의 위치 표시는 PROJECT-001.
  - 빈 목록과 검색 결과 없음은 구분해 안내한다.
- 완료 기준: 한글·영문 대소문자 검색, 결과 없음, 검색어 지우기와 제목 일치 우선순위를 note_003 테스트로 확인한다.
