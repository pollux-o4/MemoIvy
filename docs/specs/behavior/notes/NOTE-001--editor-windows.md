# NOTE-001 · 메모 창 생명주기

- 조건: 새 메모를 만들거나 기존 메모를 연다.
- 계약
  - 새 메모는 생성 저장 성공 후 목록과 편집 창에 나타난다.
  - 같은 ID의 메모는 기존 편집 창을 재사용한다.
  - 창을 닫아도 목록의 메모는 유지된다. 여러 메모는 독립 창에서 편집한다.
  - 목록과 캔버스는 홈 자리 하나를 나눠 쓴다. 한쪽을 열면 다른 쪽은 저장 후 닫힌다.
  - 목록 창 닫기 시 편집 창이 남아 있으면 목록을 숨긴다.
  - 메모·캔버스 창을 닫은 뒤 편집 창이나 홈 창이 하나도 보이지 않을 때만 목록으로 돌아온다. 설정 같은 보조 창은 보이는 창이 없을 때만 목록을 띄운다. 닫기 버튼과 OS 닫기는 같은 규칙을 따른다.
  - 변경 근거(2026-11-24): 작업 창이 남아 있는데 목록이 떠 흐름을 끊던 동작을 고친다.
- 실패·복구: SAVE-002.
- 완료 기준: 동일 메모 재열기 시 창 하나, 닫기·재실행 후 재열기 가능, 목록·캔버스가 동시에 보이지 않음.
- 검증: desktop `window_policy.test.cjs`, e2e `마지막 메모·캔버스 창을 닫을 때만`·`메모 창의 이동 메뉴`.
