# FOCUS-001 · 창별 입력 소유권

- 계약: 목록·메모 창이 비활성화되면 내부 키보드 포커스를 명시적으로 해제해 이전 입력기 컨텍스트를 끝낸다. 재활성화 시 다른 포커스가 없으면 이전 위젯을 복원한다.
- 완료 기준: 검색창↔메모를 마우스로 반복 전환할 때 본문 입력은 해당 메모에 저장되고 검색어는 유지된다. 강제 windowfocus 명령으로 전환을 우회하지 않는다.
- 검증: focus_001_ui_smoke, GTK 위젯 검사의 focus_001_releases_and_restores_input_owner.
- 검증 한계: X11 합성 검사에서는 보고된 한글 오입력을 재현하지 못했다. Wayland·실제 한글 입력기에서의 해결 여부는 별도 확인이 필요하다.
