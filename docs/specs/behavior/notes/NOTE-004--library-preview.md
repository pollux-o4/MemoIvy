# NOTE-004 · 목록 본문 더 보기

- 범위·근거: 블로그의 펼침 효과를 목록 메모 카드에 적용한다. 프로젝트별·검색·최근 보기의 본문이 있는 메모가 대상이다. 프로젝트 머리글의 하위 메모 수·트리 펼침은 PROJECT-002를 유지한다.
- 기본: 제목 아래 본문을 실제 줄바꿈 기준 2줄까지 보인다. 넘칠 때만 하단 그라데이션과 UI-001의 SVG 펼침 버튼을 표시한다. 창 너비·글꼴 변경에도 넘침 여부를 다시 판단한다.
- 조작: 공통 SVG 버튼은 목록 안에서 본문 전체를 펼치고 접힘 아이콘으로 바뀐다. 제목·본문 클릭은 기존 편집기를 연다. 목록 보기만으로 원문·수정 시각·프로젝트 상태를 바꾸지 않는다.
- 모션: 높이·하단 가림·화살표 방향을 약 300ms 동안 감속 전환한다. 진행 중 다시 누르면 현재 높이에서 반전한다. 시스템 애니메이션이 꺼져 있으면 즉시 전환한다.
- 표시·상태: Markdown 서식은 읽을 수 있는 텍스트로, 이미지는 기존처럼 설명으로 표시한다. 펼침은 현재 카드에만 유지하며 검색·목록 재생성·재실행 시 접힌 상태로 돌아간다. 원문은 편집기에서 확인한다.
- 접근성·복구: Tab·Space·Enter, 펼침 상태와 제어 대상 관계를 제공한다. 버튼 실행은 같은 위젯에서 처리해 포커스를 유지한다. 진행 중 재입력·창 크기 변경은 현재 상태로 재배치하며 메모 저장에 관여하지 않는다.
- 검증: `mise run test note_004`가 본문 끝 보존·단문/줄바꿈 넘침·중간 반전·유휴 종료·모션 줄이기를 확인한다. `python3 -m tools.behavior.lifecycle.note_004_ui_smoke`는 OPS-003의 Xvfb·Openbox 환경에서 포인터·Space/Enter·360px·편집기 분리·메모 보존을 확인하고 PNG를 남긴다. 밝은/어두운 테마로 실행하며 실제 Wayland·스크린리더 검증과 구분한다.
