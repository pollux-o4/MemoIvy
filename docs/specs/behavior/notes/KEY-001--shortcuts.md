# KEY-001 · 키보드 조작

- 앱 창: Ctrl+N 새 메모, Ctrl+F 목록 검색·검색어 선택, Ctrl+W 현재 창 정상 닫기, F1 단축키 안내. 새 메모·닫기는 기존 저장·실패 복구 경로를 사용한다.
- 편집(FMT-002): Ctrl+B 굵게, Ctrl+I 기울임, Ctrl+Shift+X 취소선, Ctrl+K 링크(URL 선택), Ctrl+1/2 제목·소제목, Ctrl+Shift+7/8/9 번호·글머리·체크 목록.
- 편집 계약: 선택 영역 또는 현재 줄에 적용하고 같은 서식은 해제한다. 한 번의 undo로 복구하며 편집 잠금·조합 중에는 서식 변경을 적용하지 않는다. Ctrl+Enter 체크 변경(체크 항목이 아닌 줄에서는 커서 아래 링크 열기), Ctrl+Shift+M 원문 전환은 유지한다.
- 캔버스: 선택·보기 키는 CANVAS-001·CANVAS-002, 정렬 키는 CANVAS-003, 삭제·완료·연결 키는 CANVAS-004. 입력 위젯·팝오버에 포커스가 있으면 그 위젯이 키를 우선 처리한다.
- 안내: 메모 더보기 메뉴의 단축키·서식 도움말 항목과 F1 창. 창은 동작마다 키를 한 줄씩 보이고 서식 줄에는 Markdown 입력 문법을 함께 보인다. 새 메모·검색·캔버스 도구 tooltip에 해당 키를 표시한다.
- 검증: fmt_002 단위 검사와 GTK 위젯 반복 토글·undo 검사, key_001_ui_smoke의 실제 키 입력·검색 포커스·닫기 저장.
