# PROJECT-002 · 라이브러리 펼침 상태

- 근거·목표: 사용자 제공 화면에서 모든 프로젝트가 펼쳐져 목록이 길어짐. 첫 진입에서 최상위 목록을 보고, 이후에는 본인이 펼쳐 둔 맥락으로 복귀한다. 합성 E2E로 검증하며 사용자 연구 결과는 없다.
- 기본: 기록 없는 프로젝트는 접힌다. 기존 화살표가 펼침·접힘을 담당하고, 제목은 설명 메모, 들어가기 아이콘은 캔버스를 연다. 기존 동작의 의미를 유지한다.
- 상태: 프로젝트별로 기억하며 부모를 접어도 하위의 선택은 보존한다. 재실행에도 복원한다. 삭제되거나 더 이상 프로젝트가 아닌 항목의 기록은 다음 상태 저장 때 정리한다.
- 검색·최근: 접힘과 관계없이 내부 메모를 경로와 함께 표시한다(NOTE-003). 검색 해제·프로젝트별 보기 복귀는 기존 펼침 상태로 돌아간다. 검색이나 보기 전환으로 기록을 바꾸지 않는다.
- 입력·접근성: 펼침 버튼은 Tab으로 접근하고 Space/Enter로 실행한다. 접근성 이름과 expanded 상태를 제공하며 실행 후 동일 버튼에 포커스를 유지한다. 좁은 창에서도 기존 조작을 유지한다. 새 애니메이션은 없다.
- 저장·복구: 메모와 별도 `library.json`에 사용자 전용 권한으로 원자 저장한다. 손상·읽기 실패 시 접힌 상태로 열며 메모 원본을 보존한다. 쓰기 실패는 대화상자로 알리고 현재 세션의 조작은 유지한다. 저장 위치 복구 후 다음 접힘·펼침에서 다시 저장한다.
- 검증: `mise run test project_002`, `mise run test:arch`. 실제 앱 E2E는 `timeout 60s dbus-run-session -- xvfb-run -a python3 -m tools.behavior.lifecycle.project_002_ui_smoke`; X11·Openbox·xdotool·Pillow 필요, 도구 경로는 기존 MEMOIVY 환경변수 사용. 밝은/어두운 테마에서 카드 표시 수·키보드 연속 조작·중첩 상태·검색·최근·재시작·360px 창·손상·쓰기 실패 복구·메모 보존을 확인하고 PNG를 남긴다. 실제 Wayland·스크린리더 검증은 포함하지 않는다.
