# PROJECT-001 · 프로젝트(들어가는 캔버스)

## 범위·근거

- 사용자 목표: 메모가 많아져도 프로젝트 단위로 보고, 깊은 곳까지 빠르게 오간다. 근거는 사용자 요청(ComfyUI 서브그래프처럼 노드를 묶어 또 하나의 캔버스로 들어가기, 자주 가는 곳 자동 바로가기)이며 실제 사용자 관찰 자료는 없다.
- 모델: `canvas.project`가 프로젝트 정체성이다(PROJECT-003). 프로젝트 메모의 본문은 프로젝트 설명이며, 비어 있어도 프로젝트로 남는다. 포함 관계 저장은 DATA-001, 방문 기록은 NAV-001.

## 캔버스 단계

- 캔버스는 한 번에 한 단계(최상위 또는 프로젝트 하나)의 카드만 보여 준다. 깊이는 최상위 아래 세 단계까지다.
- 프로젝트 카드는 겹쳐 쌓인 종이 모양, 하위 전체 메모 수, 자기+하위 할 일 진행 막대와 들어가기 버튼을 표시한다.
- 들어가기: 두 번 누르기·Enter·카드의 들어가기 버튼·선택 패널. Shift+Enter는 설명 메모를 연다. 나오기: 선택이 없을 때 Esc, Alt+↑, 경로의 상위 항목. 나오면 방금 있던 프로젝트 카드를 선택한다.
- 단계마다 마지막 화면 위치를 세션 동안 기억한다. 처음 들어가면 내용 전체를 맞춰 보여 준다.
- 다른 단계의 메모로 이어지는 연결은 이 단계에서 그 메모를 담은 카드끼리의 점선으로 투영한다. 투영선은 편집·신호 대상이 아니다. 단계 밖 대상으로 가는 연결은 숨긴다.

## 묶기·옮기기

- 선택을 새 프로젝트로 묶기(Alt+G, 정렬 막대): 선택 영역 왼쪽 위에 프로젝트 메모를 만들고 선택을 그 안으로 옮긴 뒤 이름을 적도록 편집기를 연다. 안쪽 배치는 유지한다.
- 카드를 프로젝트 카드 위에 끌어 놓으면 그 안으로 옮긴다. 놓을 곳은 점선 테두리로 미리 보인다. 키보드 대체 경로는 선택 패널의 ‘프로젝트로 옮기기’와 ‘밖으로 꺼내기’(Alt+Shift+G)다. 옮긴 묶음은 대상 단계의 빈자리에 모양을 유지해 놓는다.
- 자기 자신·자기 하위로의 이동과 깊이 초과는 거부한다. 묶기·옮기기는 캔버스 되돌리기로 복구한다(프로젝트 메모 생성 자체는 되돌리지 않음, CANVAS-001).
- 프로젝트 메모를 지우면 안의 메모는 한 단계 위로 올라간다. 보던 프로젝트가 지워지면 최상위로 돌아간다. 새 메모는 지금 보는 단계에 만든다(캔버스 Ctrl+N·새 메모).

## 길 안내

- 왼쪽 위에 경로(전체 › … › 현재)와 바로가기 칩을 둔다. 프로젝트가 하나도 없으면 숨긴다. 좁은 창에서는 가운데 경로를 줄이고 칩을 숨긴다.
- 바로가기는 고정(☆)한 프로젝트가 먼저, 이어서 NAV-001 순위로 최대 5개다. 현재 경로에 있는 곳은 빼고, 이유(고정·자주 방문)를 툴팁으로 보인다. 순서는 쓰는 중이 아니라 단계를 옮길 때만 바뀐다.

## 전환 모션

- 들어가기: 누른 프로젝트 카드의 자리에서 테두리가 화면 전체로 커지고, 그 안에 새 단계가 처음부터 보인다. 원래 카드 그림은 앞쪽 절반에서 녹고 모서리는 카드 반지름에서 직각이 된다. 뒤 화면은 카드 쪽으로 살짝 다가오며 옅게 어두워진다.
- 나오기: 정확히 반대로 화면이 방금 있던 프로젝트 카드 자리로 줄어들고 뒤쪽 절반에서 녹아 실제 카드가 드러난다. 그 카드가 기억된 화면 밖이면 배율을 유지한 채 보이도록 옮긴다. 카드 선택·패널은 전환이 끝난 뒤 반영한다.
- 따라갈 카드가 없으면(경로·바로가기로 건너뛰기) 화면 가운데의 조금 작은 상자에서 시작하거나 끝나며 카드 그림을 겹치지 않는다.
- 테두리·카드 그림·그림자·카메라는 넘치지 않는 스프링 하나로 함께 움직인다. 빈 화면을 거치지 않는다. 전환 중 입력은 이전 단계를 바꾸지 않는다. 비용 기준은 CANVAS-002.
- 모션 줄이기에서는 단계를 즉시 바꾸고 카메라를 바로 놓는다(CANVAS-002).

## 목록 화면

- ‘프로젝트별’(기본)은 프로젝트를 먼저, 형제끼리는 하위 전체의 최근 수정 순으로 들여 써 보여 준다. 프로젝트 줄은 접기/펼치기(PROJECT-002의 저장 상태), 메모 수, 할 일 진행, 캔버스에서 열기를 제공한다. ‘최근’은 기존 NOTE-003 순서다. 프로젝트가 없으면 전환을 숨긴다.
- 검색 중에는 NOTE-003 순서의 평면 목록에 각 메모의 위치(프로젝트 경로)를 함께 표시한다.
- 카드는 중립 표면에 메모 색 띠, 제목·본문 미리보기(NOTE-004)와 할 일 칩으로 정보 밀도를 높인다.

## 완료 기준

- project_001 GTK 시나리오: 단계 필터·투영 연결·진행 요약, 들어가기·나오기와 선택 복귀, 안에서 만든 메모의 소속, 묶기와 되돌리기, 옮기기와 순환 거부, 고정 바로가기 순서와 현재 위치 제외, 보던 프로젝트 삭제 시 복귀와 자식 보존.
- project_001(저장 계층): 깊이·순환·자기 포함 거부, 하위 포함 이동 깊이 계산, 삭제 시 자식 올리기, 순환을 만드는 되돌리기 스냅숏의 포함 관계 보존. project_002: 목록 트리 순서·하위 진행·접기·위치 표시.
- 밝은/어두운 테마 렌더링을 합성 데이터로 확인한다. 바로가기 유용성·발견성은 실제 사용 관찰 전까지 미확인이다.
