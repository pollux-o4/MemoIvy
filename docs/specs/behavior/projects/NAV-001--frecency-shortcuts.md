# NAV-001 · 방문 기록과 바로가기 순위

- 저장: 메모 파일 옆 `navigation.json`(소유자 전용 권한, 원자적 교체). 프로젝트 UUID별 방문 수·마지막 방문 시각만 담는다. 메모 원본과 분리된 파생 데이터라 읽기 실패·손상 시 빈 기록으로 시작하고, 쓰기 실패는 경고만 남기며 메모 저장을 막지 않는다.
- 기록: 캔버스에서 프로젝트 단계로 들어갈 때 1회. 지워진 프로젝트의 기록은 삭제 시 지운다. 최대 64개를 넘으면 점수가 가장 낮은 기록을 버린다.
- 순위(frecency): 방문 수 × 최근성 가중치(4일 미만 1.0, 14일 0.7, 31일 0.5, 90일 0.3, 그 이상 0.1). 같은 점수는 최근 방문이 앞이다. 지금 존재하는 프로젝트만 후보다.
- 사용자 제어: 고정(☆)이 자동 순위보다 항상 앞이다. 고정은 메모의 캔버스 속성으로 저장된다(DATA-001).
- 완료 기준: nav_001 테스트로 순위·재시작 유지·손상 복구·권한을 확인한다. 가중치 구간은 제품 결정이며 사용자 연구 결과가 아니다.
