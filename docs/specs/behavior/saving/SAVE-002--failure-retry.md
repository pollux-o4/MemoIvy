# SAVE-002 · 저장 실패와 재시도

- 조건: 편집·생성·삭제·닫기 중 파일 쓰기가 실패한다.
- 계약
  - 실패를 표시하고 최신 편집 내용과 재시도 수단을 유지한다.
  - 실패한 저장으로 durable revision을 전진시키지 않는다.
  - 닫기 대기를 취소하고 편집을 복구한다.
  - 생성·삭제 실패로 다른 메모의 최신 편집을 과거 snapshot으로 되돌리지 않는다.
- 다른 창과 겹친 본문 저장
  - 다른 창이 위치·크기·색 등 본문 밖만 바꿨으면 충돌로 막지 않고 최신 revision으로 다시 저장한다. 판단은 편집 출발 본문과 최신 본문 비교다.
  - 다른 창이 본문을 바꿨으면 덮어쓰지 않고 "여기 쓴 내용 남기기"·"다른 창 내용으로 바꾸기"를 고르게 한다. 고르기 전에는 닫기를 막는다.
  - 메모 창과 캔버스 정보 패널이 같은 규칙을 따른다.
- 완료 기준: 저장 경로 장애→오류·닫기 차단→경로 복구→재시도→최신 내용 보존. 캔버스가 위치를 바꾼 직후 메모 창 입력→저장됨→닫힘.
- 검증: SAVE-002 — e2e `캔버스의 위치 변경은…`, `캔버스 인스펙터로 제목을…`, `text_write.test.ts`, 스토리 `SaveFailure`·`SaveConflict`.
