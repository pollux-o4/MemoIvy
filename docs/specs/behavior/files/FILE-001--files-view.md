# FILE-001 · 파일 화면과 삭제 정책

- 범위: 더보기 메뉴의 "파일" 창. 메모에 쓰는 첨부의 사용처 확인·다시 쓰기·영구 삭제. 저장 형식은 DATA-003, 메모 안 표시는 FMT-004.
- 목록
  - "사용 중"·"사용 안 함" 전환과 각 개수를 보인다. 썸네일 격자는 최근에 쓴 순서다. 빈 상태에는 할 일을 안내하는 한 줄을 둔다.
  - 썸네일을 고르면 옆 상세에 미리보기·크기·추가 날짜와 사용처를 보인다. 사용 중이면 쓰는 메모 목록이고 누르면 그 메모를 연다. 사용 안 함이면 마지막으로 쓴 메모와 그 시점이다(메모가 지워졌으면 "삭제된 메모").
- 다시 쓰기
  - 썸네일을 메모 편집 창으로 끌어 놓으면 놓은 위치에 참조 줄을 넣는다.
  - "참조 복사"는 참조 문법을 클립보드에 넣는다. 메모에 붙이면 같은 파일을 다시 쓴다.
- 삭제 정책
  - 본문에서 이미지를 지우거나 메모를 삭제하면 파일은 사용 안 함으로 옮겨질 뿐 지워지지 않는다.
  - 영구 삭제는 사용 안 함 항목에서만 한다. 하나 삭제와 "사용 안 함 모두 삭제" 모두 취소가 기본인 확인창을 거친다(NOTE-002와 같은 형태).
  - 사용 중인 항목에는 삭제 버튼이 없다. 확인 사이에 다시 쓰이게 되면 삭제를 거부하고 목록을 새로 고친다.
  - "30일 지난 사용 안 함 자동 정리"는 기본 꺼짐이고 켜면 앱 시작 때 적용한다(DATA-003).
- 갱신: 메모 저장·삭제로 사용처가 바뀌면 열린 파일 창을 다시 그린다. 같은 창은 하나만 열고 다시 열면 앞으로 가져온다.
- 모션: 상세 전환은 160ms 크로스페이드, 썸네일 호버는 살짝 떠오르는 그림자. 모션 줄이기를 따른다.
- 완료 기준: file_001 위젯 테스트로 분류·사용처 이동·삭제 확인·사용 중 삭제 거부·창 재사용을 확인한다. 실제 앱에서 끌어 놓기 재사용을 확인한다.
