# PERF-002 · 앱 품질 감사

- 범위: 웹 페이지 감사 도구(Lighthouse)의 성능·권장사항 관점을 네이티브 GTK 앱에 맞춘 지표. Lighthouse는 웹 문서를 대상으로 하므로 직접 실행하지 않는다. 스크린리더 등 부차적 접근성은 UX-001에 따라 범위에서 제외한다. 입력 저장 경로는 PERF-001.
- 조건: 릴리스 빌드, 합성 메모 300개(각 약 500자), 창 1160×760, Xvfb 소프트웨어 렌더링.

| Lighthouse 관점 | 앱 지표 | 기준 |
|---|---|---|
| 첫 화면 표시 | 실행→목록 창 표시 | ≤1초 |
| 첫 화면 표시 | 캔버스 버튼→창 표시 | ≤1초 |
| 입력 반응·프레임 | 팬 프레임 간격 p95 (ngl) | ≤20ms |
| 입력 반응·프레임 | 팬 프레임 간격 p95 (cairo) | ≤33ms |
| 입력 반응·프레임 | 배율 변경·전체 재배치 p95 (ngl) | ≤60ms |
| 자원 낭비 없음 | 움직임 종료 후 유휴 CPU | ≤2% |
| 대비 | 본문·보조 글자, 메모 색, 강조·위험 버튼 | ≥4.5:1 (완료 카드 보조 글자 ≥3:1) |
| 권장사항 | 조작 시나리오의 GTK 경고·CRITICAL·패닉 | 0건 |

- 계약: 화면 밖 카드는 측정·그리기에서 제외한다. 저배율에서는 그림자와 글자를 생략한다. 그릴 내용이 없는 HUD는 숨긴다. 내용이 바뀌지 않으면 목록을 다시 만들지 않으며 항목 메뉴는 처음 열 때 만든다.
- 측정: `tools/quality/perf_002_app_audit.py`(시작·메모리·유휴·대비), `LSM_CANVAS_PERF=1`인 릴리스 테스트(프레임). 실행 방법은 OPS-003.
- 한계: 합성기·실제 GPU·Wayland 프레임률은 포함하지 않는다. 사용자 체감 평가가 아니다. 메모리는 기준 없이 기록만 한다.
