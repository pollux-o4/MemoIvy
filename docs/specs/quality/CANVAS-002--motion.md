# CANVAS-002 · 캔버스 모션과 피드백

- 범위: 확대·전체 보기, 방향 신호·도착, 선택·호버 깊이. 위치·연결 저장 계약은 CANVAS-001.
- 확대: 현재 뷰포트 중심을 유지하며 짧은 가감속 보간을 수행한다. 전환 중 추가 입력은 현재 화면에서 새 목표로 이어지고 드래그 시작은 확대를 중단한다. 전체 보기는 원점과 전체 배율로 전환한다.
- 신호: 직계 연결을 따라 일회성으로 이동하고 도착 카드 테두리를 강조한 뒤 사라진다. 대상 완료 상태를 바꾸지 않는다. 반복 전송은 최근 신호로 대체한다.
- 모션 줄이기: GTK 애니메이션 비활성화 시 확대를 즉시 반영하고 신호는 정적 도착 표시만 제공한다. 실행 중 설정 변경도 진행 중 전환에 적용한다.
- 자원·입력: 활성 전환이 끝나면 프레임 콜백을 중단한다. 확대 프레임마다 카드·컨트롤을 재생성하거나 저장 요청을 만들지 않는다. 삭제된 컨트롤의 키보드 포커스는 연결 추가로 복구한다.
- 완료 기준: 보간의 시작·끝·단조성과 중간 재목표 지정, 기존 위젯 유지, 모션 줄이기, 종료 후 유휴 상태를 CANVAS-002 테스트로 확인한다. 밝은/어두운 테마의 호버·선택·확대·도착은 실제 GTK 화면에서 검토한다.
- 한계: 시각 스타일의 선호를 사용자 연구 결과로 해석하지 않는다. macOS와 동일한 플랫폼 합성 효과를 보장하지 않는다.
