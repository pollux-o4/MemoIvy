# PERF-001 · 입력 반응성과 저장 병합

- 조건: 메모 100개×약 1KiB, 편집 본문 10KiB, 연속 입력 100회.
- 계약
  - 입력 callback에서 파일 쓰기·동기화·전체 목록 재생성을 수행하지 않는다.
  - 단일 writer 실행 중의 변경은 최신 snapshot으로 병합한다. 저장 완료가 GTK 스레드를 막지 않는다.
- 합성 probe 기준
  - writer 500ms 지연, 시작 시 저장 1회 진행 중, 입력 간격 2ms.
  - 재현 callback p95 ≤8ms, 5ms heartbeat 최대 간격 ≤50ms, 저장 횟수 2회.
- 완료 기준: 측정 환경·결과와 실제 앱 전체 callback·입력→프레임 측정 여부를 구분해 기록한다.
