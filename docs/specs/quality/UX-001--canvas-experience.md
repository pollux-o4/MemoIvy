# UX-001 · 캔버스 사용 경험

## 범위·판단 기준

- 대상: 로컬 개인용 시각 메모 사용자. 목적은 생각 배치·방향 관계 이해·원본 수정·복구다. 요구 근거는 사용자 요청이며 실제 사용자 연구 자료는 없다.
- 사용자 결정으로 스크린리더 지원·전용 보조기술 검증은 이번 범위에서 제외한다. 키보드·포인터, 대비·가독성, 모션 줄이기, 상태 표시·복구는 유지한다. 포괄적인 접근성 적합성을 주장하지 않는다.
- 합성 조작 검증은 작업 성공·저장 결과를 확인한다. 배우기 쉬움·만족도·실제 사용자 성공률의 증거로 일반화하지 않는다.

## 작업·복구 계약

| 목표 | 완료 증거 | 오류·중단 복구 |
|---|---|---|
| 메모를 배치·이동 | 동일 UUID의 좌표 변경과 재시작 복원 | 드래그 취소·되돌리기, 방향키 대체 조작 |
| 관계 만들기·따라가기 | 선택 패널의 전체 문맥으로 대상 구분, 연결 대상 선택으로 이동 | 연결 해제는 본문 보존, 되돌리기로 복구 |
| 키보드로 흐름 구성 | Tab 포커스와 선택 패널이 같은 메모를 가리킴 | 위젯 갱신 시 포커스 복구 |
| 원본 수정 | 내용·색상 공유, 카드 중복 없음 | 기존 편집 undo와 저장 실패 재시도 |
| 완료 흐름 이해 | 완료와 신호 재생 구분, 다음 메모 자동 완료 없음 | 모션 줄이기 시 정적 도착 표시 |

## 확인 방법·한계

- CANVAS-001·CANVAS-002 위젯 검사: 연결·완료·되돌리기·저장 실패·모션·빈 상태.
- canvas_001_ui_smoke: 실제 GTK 포인터 드래그, Tab·방향키, 작은 창, 정상 종료·재시작의 좌표·식별자 보존. 밝은/어두운 테마로 반복한다.
- 실제 사용성 확인의 담당은 제품 소유자다. 후속 확인 시 합성 메모로 ‘세 생각을 배치하고 순서 연결 → 잘못 연결한 관계 복구 → 원본 수정 → 재시작 후 이어가기’를 설명 없이 시도한다. 관찰 전까지 발견성·선호 검증은 미확인으로 유지한다. 참여자 모집·녹화·개인정보 수집은 수행하지 않았다.
- 실제 Wayland·한글 IME 및 다양한 배율·글꼴 환경은 별도 검증 대상이다.
