# UI-001 · 일관된 아이콘과 창 조작

- 범위: 창 조작·팔레트·더 보기·새 메모·캔버스 도구·정렬.
- 계약
  - 같은 문법의 SVG를 내장하고 현재 CSS 글자색·배율에 맞춰 렌더링한다. 구체 자산·치수는 icons·styles가 원본이다.
  - 메뉴는 화살표 없는 둥근 표면으로 짧게 확대·페이드되며 항목은 아이콘·이름·단축키 힌트 순서다. 삭제는 위험 색으로 구분한다. 메뉴가 열린 동안 버튼 툴팁을 표시하지 않는다.
  - 최대화 상태에 따라 복원 아이콘·툴팁·접근 가능한 이름을 전환한다.
  - 닫기·최소화·확대·복원은 GTK 창 동작으로 연결하고 키보드 focus를 표시한다.
- 언어 독립적인 내용 펼침
  - 프로젝트 내용과 메모 본문은 공통 `disclosure` SVG 버튼을 사용한다. 화면에 펼침·접힘 문자를 붙이지 않고 내용 끝에 둔 단일 방향 SVG와 회전 모션으로 상태를 전달한다. 전환 전후에 조작 영역의 치수를 유지한다.
  - 포함 관계는 프로젝트 표면 안의 카드로 표현한다. 실제 펼침 범위·기본 상태·복원은 PROJECT-002·NOTE-004를 따른다.
  - 버튼의 접근성 이름·툴팁은 상태와 제어 대상을 설명한다. 한국어 로케일과 영어 기본 설명을 제공하고, 새 언어는 같은 문구 원본에 추가한다. 시각적 조작은 언어 선택과 독립적이다.
  - Tab·Space·Enter와 expanded/controls 관계, 테마·배율·시스템 모션 줄이기를 유지한다. 모션 중 목록 전체나 하위 카드를 재생성하지 않는다.
  - 시각 변경은 사용자 참조·관찰된 문제·콘텐츠 역할에 근거를 남긴다. 아이콘·선·색·배경이 같은 역할을 반복하면 줄인다. 제목과 조작의 정렬·반복 간격·내포 카드의 여백을 실제 본문이 있는 화면에서 검토한다. 선택 이유: ADR-0012.
- 완료 기준: 모든 SVG 1×/2× decode, 라이트·다크·좁은 창·클릭 동작·포커스 확인.
