# DATA-001 · 메모 파일 형식과 로드

- 형식: Note 객체의 JSON 배열. 필드·타입 원본은 `Note`, 허용 색상은 `COLORS`다.
- 의미: id=메모의 안정적 UUID, text=일반 텍스트, color=팔레트 키, modified=Unix 초 단위 수정 시각.
- 검증
  - JSON·필수 필드·타입·UUID, 중복 ID, 허용 색상을 검사한다.
  - 파일이 없으면 빈 목록으로 시작한다. 다른 읽기 오류는 원본을 보존하고 표시한다.
- 호환성
  - 현재 형식은 버전 필드가 없는 배열이며 Serde가 추가 필드를 허용한다.
  - 향후 필수 필드·허용 값 변경 시 기존 파일 변환 또는 명시적 오류·원본 보존을 제공한다.
- 완료 기준: 한글·이모지 roundtrip, 손상·중복 ID·잘못된 색상 거부와 원본 보존.
