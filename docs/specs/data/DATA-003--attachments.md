# DATA-003 · 첨부 파일 저장과 참조

- 범위: 메모 이미지의 저장 위치·파일 이름·본문 참조·사용처 색인. 선택 이유: ADR-0011. 화면 동작은 FMT-004·FILE-001.
- 저장
  - 위치: notes.json 옆 `assets/`. 파일 이름은 바이트의 SHA-256 소문자 16진수 64자와 형식 확장자(`png`·`jpg`·`gif`·`webp`)다.
  - 형식은 확장자나 MIME이 아니라 파일 앞부분 서명으로 판별한다. 그 밖의 형식과 20MiB 초과는 거부한다.
  - 쓰기는 DATA-002와 같은 임시 파일·동기화·교체를 쓰고 권한은 소유자 전용이다. 이미 같은 해시가 있으면 다시 쓰지 않는다.
- 참조
  - 본문 문법: 한 줄 전체가 `![설명|너비](asset:<해시>)`. `|너비`는 선택이며 64~4096 사이 정수 픽셀이다. 설명에는 `]`·`|`·줄바꿈을 쓰지 않는다.
  - 사용 판정: 본문 어디에든 `asset:<해시 64자>`가 있으면 사용 중이다. 문법이 깨져도 판정은 같다.
- 사용처 색인 `assets.json`
  - 해시별 추가 시각, 마지막으로 쓴 메모 UUID, 사용 안 함이 된 시각을 기록한다. 30일 자동 정리 설정도 여기에 둔다.
  - 파생 데이터다. 없거나 손상되면 assets 폴더와 메모 본문으로 다시 만들고, 이력(마지막 메모·시각)만 잃는다. 저장 실패는 메모 저장을 막지 않는다.
  - 판정은 메모 저장 성공·메모 삭제·앱 시작 때 한다. 입력 중에는 하지 않아 잘라내기·붙여넣기 사이에 사용 안 함으로 바뀌지 않는다.
- 삭제
  - 사용 중인 파일은 삭제를 거부한다. 판정 직전에 현재 본문으로 다시 확인한다.
  - 자동 정리는 켜져 있을 때만, 사용 안 함이 된 지 30일 지난 파일을 앱 시작 때 지운다.
- 호환성: 이 기능 전 notes.json은 그대로 읽는다. 첨부를 모르는 이전 버전은 참조 줄을 원문으로 보여 준다. 색인 추가 필드는 무시한다.
- 완료 기준: data_003 테스트로 형식 판별·크기 거부·중복 저장·권한, 참조 판정·사용 안 함 전환·마지막 메모 기록, 사용 중 삭제 거부, 손상 색인 복구, 30일 자동 정리 경계를 확인한다.
