# DATA-003 · 첨부 파일 저장과 참조

- 범위: 메모 이미지의 저장 위치·파일 이름·본문 참조·사용처 색인. 선택 이유: ADR-0011. 화면 동작은 FMT-004·FILE-001.
- 저장
  - SQLite에 바이트와 메타데이터를 저장한다. 식별자는 바이트의 SHA-256 소문자 16진수 64자다.
  - 이미지 MIME은 PNG·JPEG·GIF·WebP를 허용하고 바이트 서명과 대조한다. 20MiB 초과는 거부한다.
  - 쓰기는 DATA-002의 트랜잭션을 사용한다. 이미 같은 해시가 있으면 다시 쓰지 않는다.
- 참조
  - 본문 문법: 한 줄 전체가 `![설명|너비](asset:<해시>)`. `|너비`는 선택이며 64~4096 사이 정수 픽셀이다. 설명에는 `]`·`|`·줄바꿈을 쓰지 않는다.
  - 사용 판정: 본문 어디에든 `asset:<해시 64자>`가 있으면 사용 중이다. 문법이 깨져도 판정은 같다.
- 사용처와 이력
  - 해시별 추가 시각, 마지막으로 쓴 메모 UUID, 사용 안 함이 된 시각을 기록한다. 30일 자동 정리 여부는 엔진 설정에 둔다.
  - 판정은 엔진의 메모 변경과 함께 갱신한다. 입력 중에는 하지 않아 잘라내기·붙여넣기 사이에 사용 안 함으로 바뀌지 않는다.
- 삭제
  - 사용 중인 파일은 삭제를 거부한다. 판정 직전에 현재 본문으로 다시 확인한다.
  - 자동 정리는 켜져 있을 때만, 사용 안 함이 된 지 30일 지난 파일을 앱 시작 때 지운다.
- 호환성: 이전 데이터의 `notes.json` 옆 `assets/`와 `assets.json`을 읽고 원본을 보존한다. 본문의 참조 해시는 유지한다.
- 검증: 엔진의 이전 첨부 가져오기 및 Electron E2E의 이전 데이터 재열기와 이미지 편집 검증을 사용한다.
