# C3 · 저장 컴포넌트

- Electron main이 창과 엔진 프로세스를 연결한다. `EngineTransport`가 요청의 응답을 매칭하고 스냅샷 이벤트를 전달한다.
- 창 정책(`window_policy.cjs`)이 목록·캔버스 홈 자리 교체와 마지막 메모·캔버스 창이 닫힐 때의 목록 복귀를 결정한다(NOTE-001).
- Rust 엔진은 메모·배치·환경설정·첨부 명령을 처리한다. 도메인 유효성 검증과 충돌 확인을 저장 단계에서 강제한다.
- SQLite가 확정 원본이다. 읽기 모델은 스냅샷으로 발행하고 변경은 트랜잭션으로 저장한다. 사용자 편집 초안은 각 화면이 관리한다.
- 이전 데이터 가져오기는 전용 어댑터가 맡는다. 원본을 잠그고 백업을 검증한 뒤 메모와 첨부를 가져온다.
