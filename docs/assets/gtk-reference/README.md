# UI-REF-001 · GTK 원본 화면

실제 GTK 앱의 위젯을 Xvfb에서 렌더링한 원본 PNG 18개다. 화면 이관·적대 검수의 기준 자산이며, 사용자 요청 없이 갱신하지 않는다.

- `manifest.json`: 이미지별 실제 치수·테마·화면 상태·데이터 해시, 캡처 시각·명령·GTK·폰트·소스 리비전과 변경 여부.
- `fixtures`: 각 화면에 사용한 정확한 메모·펼침 상태·첨부 이미지·사용처 색인. 기본 4개 메모는 MIG-001의 visual-fixture에서 시작한다.
- 범위: 목록·편집기·캔버스·빈 파일 화면·첨부 편집기·사용 중/사용 안 함 파일·중첩 프로젝트 펼침, 각각 라이트·다크.

Storybook의 GTK 원본 비교에서 같은 데이터·테마·실제 치수의 이관 화면과 비교한다. 파일 상세 화면은 내용에 따라 GTK의 최소 높이가 달라지므로 이미지별 manifest 치수를 따른다.

기준을 의도적으로 다시 캡처할 때만 실행한다.

```sh
mise run test:gtk-reference
```

이 명령은 전용 합성 데이터와 가상 화면을 사용한다. 일반 테스트에서는 캡처 환경 변수가 없어 기준 파일을 쓰지 않는다.
