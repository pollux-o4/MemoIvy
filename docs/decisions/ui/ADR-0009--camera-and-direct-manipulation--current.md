# ADR-0009 · 카메라 기반 캔버스와 직접 조작

- 대체: ADR-0008. 맥락: 고정 패널·이동 핸들·스크롤 창 구조에서 선 가림, 조작 소음, 위젯 재생성으로 끊기는 전환, 다중 정렬 불가가 드러났다. 구현 계약: CANVAS-001·CANVAS-002·CANVAS-003.
- 유지: 별도 웹 엔진 없이 GTK 카드+벡터 연결, 메모와 1:1 카드, 위치·다음 UUID·완료만 저장, 일회성 신호, 방향 연결은 수동 배치 우선.

## 선택과 트레이드오프

| 관심사 | 대안 | 선택 | 이유·대가 |
|---|---|---|---|
| 뷰포트 | ScrolledWindow / 자체 카메라 | 자체 카메라(월드 변환 1개) | 배율·이동 비용이 카드 수와 무관하고 포인터 기준 확대·중앙 맞춤·관성이 가능하다. 스크롤바가 없어 전체 보기·내용 유지 제한으로 길 잃음을 막는다. |
| 카드 입력 | 이동 핸들 / 카드 전체 끌기 | 카드 전체 | 카드마다 있던 안내 문구를 없앤다. 열기는 한 번 누르기에서 두 번 누르기·Enter로 바뀌어 처음에는 학습이 필요하다. |
| 도구 배치 | 고정 사이드바 / 떠 있는 패널 | 떠 있는 패널 | 보드 전체를 쓴다. 패널이 카드를 가릴 수 있어 키보드 이동·선택 이동은 가려진 영역을 보이는 곳으로 치지 않는다. |
| 정렬 진입점 | 패널 안 도구 / 상시 도구 막대 / 선택 시 막대 | 2개 이상 선택 시 상단 막대 | 평소 화면을 비운다. 단축키는 널리 쓰이는 Alt 계열을 따른다. |
| 모션 | 시간 기반 보간 / libadwaita / 자체 스프링 | 자체 스프링 | 진행 중 재목표에서 속도가 이어진다. 의존성을 늘리지 않는다. 플랫폼 합성 효과(반투명 흐림)는 GTK CSS로 제공할 수 없어 쓰지 않는다. |
| 렌더링 | 전체 Cairo / 카드 위젯+Cairo 선 | 유지 | 네이티브 포커스·입력을 재사용한다. 선·그리드는 소프트웨어 그리기라 큰 창에서 프레임 비용이 가장 크다. 점 개수는 배율과 무관하게 제한한다. |
| 다크 테마 | 구성요소별 `.dark` 규칙 / 토큰 교체 | 토큰 파일 교체 | 스타일 한 벌만 유지한다. CSS 변수는 GTK 4.16 이상이라 `@define-color`와 제공자 교체를 쓴다. |

## 결과

- 필요 GTK가 4.10으로 오른다(`color`·스크롤 단위). 사용 중단 API는 이유를 적어 허용한다.
- 위젯은 메모별로 재사용한다. 키보드 이동과 다중 이동, 연결 점 끌기가 같은 변경 경로(`mutate`)와 되돌리기를 공유한다.
- 사용자 관찰 자료가 없어 두 번 누르기 열기와 떠 있는 패널은 잠정적이다. UX-001의 후속 확인에서 막히면 재검토한다.
