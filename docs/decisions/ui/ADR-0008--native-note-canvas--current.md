# ADR-0008 · 네이티브 메모 캔버스

- 맥락: 가벼운 메모와 1:1로 연결된 공간 배치, 이해 가능한 방향 관계, 부드러운 이벤트 신호가 필요하다. 구현 계약: CANVAS-001.
- 별도 웹 엔진은 풍부한 그래프 생태계 대신 런타임·패키징·동기화 비용을 늘린다. GTK 카드+벡터 연결은 기존 편집·테마·저장 경로와 접근 가능한 네이티브 컨트롤을 재사용하므로 채택한다.
- 독립 카드 데이터는 자유로운 재사용 대신 메모와 내용 불일치 위험을 만든다. 메모에 위치·다음 UUID·완료 상태만 추가하여 단일 원본과 원자 저장을 유지한다. 기존 JSON 배열과 기본값 로드를 보존한다.
- 포트 드래그만 제공하면 작은 표적과 숨은 조작이 생긴다. 명시적 선택 패널과 대상 선택으로 연결하며, 핸들 드래그와 방향키로 배치한다. 직접 포트 연결 필요가 검증되면 같은 도메인 연산 위에 추가한다.
- 자동 작업 전파는 순환·분기에서 완료 의미가 불명확하다. 완료 상태는 사용자가 결정하고 직계 연결에 일회성 시각 신호만 전달한다. 애니메이션은 프레임 시계와 OS 설정을 따른다.
- 자유 배치는 사고 구조를 보존하지만 연결선 겹침이 가능하다. 방향 곡선·선택 강조와 수동 배치를 우선한다. 복잡한 다중 프로젝트·자동 선 회피가 실제 사용에서 필요해지면 그룹·라우팅을 재검토한다.
- 사용자 관찰 자료가 없어 조작 선택은 잠정적이다. 연결 생성·원본 수정·오조작 복구가 막히는 사례를 후속 사용성 검증의 재검토 조건으로 삼는다.

- 모션은 별도 motion 모듈에서 프레임 시계·취소·재목표 지정을 관리한다. 확대마다 카드를 재생성하면 포커스 손실과 프레임 지연이 생기므로 기존 위젯 변환만 갱신한다. 보간 확대와 일회성 도착 강조를 사용하고 상시 효과는 추가하지 않는다. 검증: CANVAS-002.
