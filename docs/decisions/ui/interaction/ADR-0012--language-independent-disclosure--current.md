# ADR-0012 · 언어 독립적인 내용 펼침

- 맥락: 프로젝트와 메모의 숨겨진 내용은 같은 조작인데, 문자 버튼과 왼쪽 트리 화살표가 섞여 포함 관계와 사용법이 달라 보였다. 사용자는 언어권에 관계없이 읽히는 SVG 조작을 요청했다.
- 근거: 사용자 제공 펼침 참조 https://i-can-du.tistory.com/166 및 2026-11-10 피드백(과한 두께·임의적인 문양·위계와 정렬 재검토).
- 대안: 문자형 더 보기, 트리 화살표, 공통 SVG 펼침 제어.
- 결정: 프로젝트 표면 안에 카드를 두고, 메모 본문과 프로젝트 내용에 같은 SVG 펼침 제어를 사용한다. 참조 블로그의 방향 전환을 유지하는 단일 chevron을 내용의 아래 경계에 두고, 펼침·접힘 방향만 바꾼다.
- 이유: 사용자가 제시한 블로그의 내용 공개 흐름을 재사용한다. 내용 끝의 조작은 자신이 여는 범위와 가깝고, 문자 없이 같은 동작을 반복해 익힐 수 있다. 기존 방향 기호를 쓰고 별도 복합 문양·상시 알약 테두리는 더하지 않는다. 포함 관계는 프로젝트 표면, 식별 색은 가는 띠가 담당한다. 이는 참조와 현재 화면에 근거한 설계 판단이며 사용자 연구로 입증한 결과는 아니다.
- 정렬·여백: 프로젝트 조작은 제목 줄 오른쪽에 가로 정렬해 머리글 높이를 줄인다. 펼침 제어는 메모·프로젝트 모두 자기 카드의 아래 중앙에 두며, 별도 테두리보다 내용 범위와의 근접성으로 설명한다. 자식이 부모와 같은 색이면 식별 띠를 반복하지 않는다. 호버는 대비만 바꾸고 위치를 움직이지 않는다.
- 결과: 아이콘 상태·색·모션·키보드·접근성 설명은 공통 구현에서 관리한다. 새 UI도 공통 제어를 재사용하며 설명 문구는 로케일에 맞춘다. 아이콘 이해도에 대한 다국어 사용자 연구는 별도 검증이다.
- 관련 계약: UI-001
