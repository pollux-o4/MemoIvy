# ADR-0004 · 단일 백그라운드 writer

- 대체: ADR-0003
- 맥락: 입력 반응성을 유지하면서 최신 편집·저장 완료·닫기를 구별해야 한다.
- 대안: UI 스레드의 지연 저장, 별도 순차 writer.
- 결정: GTK 스레드는 메모리와 예약을 갱신하고, 단일 worker가 소유된 snapshot을 저장한다.
- 이유: 디스크 I/O를 입력 경로에서 분리하고 저장 순서 역전을 방지한다.
- 결과: revision·durable과 실패·재시도·닫기 조율을 관리한다. 강제 종료 전 미완료 변경은 유실될 수 있다.
- 관련 계약: SAVE-001, SAVE-002, PERF-001
